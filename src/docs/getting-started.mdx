# Getting Started

Everything you need to install PulseUI and render your first component.

---

## Prerequisites

- **Node.js** >= 22.12.0
- **npm** >= 9
- **React** >= 18 (peer dependency)

---

## Installation

```bash
npm install @pulseui/react
```

---

## Importing styles

PulseUI ships its own CSS. Import it **once** in your application entry point
(e.g. `main.tsx`, `_app.tsx`, `layout.tsx`):

```tsx
import '@pulseui/react/styles';
```

If you also want access to the raw `--pulse-*` CSS custom properties in your own
stylesheets, import the tokens separately:

```css
@import '@pulseui/react/tokens';
```

> You do **not** need both. `@pulseui/react/styles` already includes the component
> styles. Use `@pulseui/react/tokens` only when you want to reference the variables
> directly in your own CSS files.

---

## Your first component

### Button

```tsx
import { Button } from '@pulseui/react';
import '@pulseui/react/styles';

export default function App() {
  return (
    <div>
      <Button label="Log in" onClick={() => console.log('login')} />
      <Button variant="primary" label="Sign up" onClick={() => console.log('signup')} />
    </div>
  );
}
```

### The rest of the library

Button is just one of 27 components. Every other one follows the same shape — a
named export, a typed props interface, and a `className` prop for overrides. Browse
the **Components** section of the sidebar for the full list, each with its own
interactive docs page and prop table generated from its TypeScript interface.

---

## Package exports

The package exposes three entry points:

| Import path | What it provides |
|---|---|
| `@pulseui/react` | All components and TypeScript types |
| `@pulseui/react/styles` | Bundled component CSS (`dist/style.css`) |
| `@pulseui/react/tokens` | Design token CSS variables only (`dist/tokens/index.css`) |

---

## TypeScript

All prop interfaces are exported and can be imported for use in your own code:

```tsx
import type { ButtonProps, ButtonVariant } from '@pulseui/react';
```
